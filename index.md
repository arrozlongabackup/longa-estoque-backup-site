# Longa Estoque Backup

Bem-vindo à página informativa do Longa Estoque Backup.

## Sobre o projeto

O Longa Estoque é um sistema de gerenciamento de estoque que utiliza PostgreSQL para armazenar os dados da aplicação.

O Longa Estoque Backup é um projeto de cópia de segurança desenvolvido para proteger os dados do sistema e permitir sua recuperação em caso de falhas.

## Integração com Google Drive

O projeto está preparando uma integração com o Google Drive, utilizando o Rclone, para realizar backups automatizados.

A solução prevê criptografia dos arquivos, verificação das transferências e testes periódicos de recuperação.

A integração ainda está em desenvolvimento e validação.

## Privacidade e segurança

Esta página é apenas informativa. Os bancos de dados e arquivos de backup não são disponibilizados publicamente neste site.

Uma política de privacidade específica será publicada neste repositório.
