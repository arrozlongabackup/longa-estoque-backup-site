# Política de Privacidade — Longa Estoque Backup

**Última atualização:** 24 de novembro de 2026

## 1. Sobre o aplicativo

O Longa Estoque Backup é uma ferramenta em desenvolvimento destinada à realização de cópias de segurança do banco de dados PostgreSQL utilizado pelo sistema Longa Estoque.

A integração planejada com o Google Drive utilizará o Rclone para transferir e recuperar arquivos de backup autorizados pelo responsável pela conta.

## 2. Informações acessadas

A integração poderá solicitar autorização de acesso ao Google Drive para armazenar, consultar, verificar e recuperar arquivos de backup.

As permissões efetivamente concedidas dependerão dos escopos configurados na integração OAuth. O acesso será utilizado exclusivamente para as operações necessárias ao serviço de backup.

Os arquivos de backup podem conter informações operacionais e dados pessoais existentes no banco de dados do Longa Estoque.

## 3. Utilização das informações

Os dados acessados serão utilizados para:

- Criar e armazenar cópias de segurança.
- Verificar a integridade das transferências.
- Recuperar informações em caso de falhas.
- Administrar os arquivos de backup autorizados.

O projeto não tem como finalidade vender informações pessoais ou utilizar os dados do Google Drive para publicidade.

## 4. Armazenamento e segurança

O sistema prevê criptografia dos backups antes do envio à nuvem, controles de acesso e procedimentos de verificação e restauração.

Essas medidas estão em desenvolvimento e serão validadas antes da utilização definitiva do serviço.

Os arquivos de backup não serão publicados neste site.

## 5. Compartilhamento de dados

Os backups serão armazenados no serviço Google Drive autorizado pelo responsável pela conta.

O acesso aos dados poderá ocorrer por ferramentas técnicas necessárias à realização das operações de backup e recuperação.

Não está previsto o compartilhamento de informações para fins comerciais ou publicitários.

## 6. Retenção e exclusão

A política operacional prevista é conservar um histórico limitado de backups, com possibilidade de remoção de versões antigas após validação dos mecanismos de recuperação e retenção.

Os prazos e procedimentos definitivos serão estabelecidos antes da entrada em produção.

## 7. Revogação do acesso

O responsável pela conta Google poderá revogar a autorização do aplicativo nas configurações de segurança da própria conta.

A revogação interromperá o acesso autorizado à API, mas não excluirá automaticamente arquivos já armazenados. A exclusão desses arquivos deverá ser realizada separadamente.

## 8. Sobre este site

Este site tem finalidade informativa e está hospedado no GitHub Pages. O GitHub poderá processar dados técnicos de acesso conforme suas próprias políticas de privacidade.
